# Migrating to 2.1: `src.*` → `agentflow_runtime.*`

Since **agentflow-runtime 2.1.0** the runtime package installs and imports
as **`agentflow_runtime`**. The generic `src` top-level that earlier wheels
shipped is now a one-file deprecated shim, kept for exactly one deprecation
window and **removed in the next major release**.

## What you need to change

| Before (deprecated) | After |
|---|---|
| `from src.serving.api.main import app` | `from agentflow_runtime.serving.api.main import app` |
| `import src.processing.local_pipeline` | `import agentflow_runtime.processing.local_pipeline` |
| `python -m src.serving.provision --schema` | `python -m agentflow_runtime.serving.provision --schema` |
| `uvicorn src.serving.api.main:app` | `uvicorn agentflow_runtime.serving.api.main:app` |
| `python -m src.processing.bridge_consumer` | `python -m agentflow_runtime.processing.bridge_consumer` |

A mechanical rewrite is safe: every dotted `src.<module>` reference becomes
`agentflow_runtime.<module>` for the runtime's top-level modules
(`constants`, `db_concurrency`, `ingestion`, `logger`, `orchestration`,
`processing`, `quality`, `serving`, `tenancy`, `version`).

## Shim semantics during the deprecation window

- `import src.X` keeps working and yields the **same module object** as
  `agentflow_runtime.X` — no double import, `isinstance` checks and module
  singletons are unaffected.
- The first `import src` emits a `DeprecationWarning`. Set
  `AGENTFLOW_SRC_SHIM_SILENT=1` to silence it while you migrate. The variable
  is parsed as a boolean — `1`, `true`, `yes` or `on`, case-insensitive —
  so `AGENTFLOW_SRC_SHIM_SILENT=0` keeps the warning rather than silencing it,
  and an unrecognised value warns too (audit F-15).
- The wheel's `src/` contains only `__init__.py`; the removal lands in the
  next major release, after which `import src` fails.

## Repository layout (for contributors)

- The tree moved to the src-layout `src/agentflow_runtime/…`; `src/` itself
  is a plain container directory (no `__init__.py`).
- The shim source lives in `packaging/src_shim/src/__init__.py` and reaches
  wheels through the hatch `only-include` + `sources` maps in
  `pyproject.toml`.
- Guards: `tests/unit/test_namespace_policy.py` (layout + no first-party
  `src.*` imports) and `scripts/wheel_smoke.py` (wheel top-level policy +
  install smoke outside the checkout, wired into the python-compat CI job).
